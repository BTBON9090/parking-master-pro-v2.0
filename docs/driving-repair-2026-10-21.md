# 驾驶与北京场景修复记录 · 2026-10-21

## 使用

在项目目录执行 `npm run dev -- --host 127.0.0.1`，打开 http://127.0.0.1:3000/。
按 Enter 进入车库，选择车型与训练场，再启动引擎。

- 按住鼠标右键并左右移动：转向；松开后行驶中逐渐回正，静止时保持角度。
- W / 上方向键：油门；Shift + W：全油门；S / 下方向键：制动。
- D / 右方向键：加挡；A / 左方向键：减挡；Q：倒挡；V：空挡并驻车。
- F：切换视角；M：设置。

## 车辆

修复进口 GLB 轮组的局部坐标和缩放，统一转向节 Y 轴与滚动 X 轴。补上跑车后轮节点识别，将 SUV / 皮卡连成一体的后轮几何拆成独立轮组。7 款车均具有四个滚动轮和两个前轮转向节。

方向盘与前轮按各车型机械转向比映射；前轮采用阿克曼内外轮差角。按模型实际轮轴位置计算轴距及车身中心相对后轴的偏移，精确积分低速停车圆弧，辅助线使用同一公式。轮胎按行驶距离滚动并体现内外轮差速。高速加入简化抓地力限制，属于游戏驾驶模型，不等同专业车辆动力学仿真。

修复速度表单位与世界行驶距离不一致。挡位转速使用传动比与轮径，换挡平滑衔接动力，新增正反向切换及过转速降挡保护。SU7 / YU7 使用单速电驱。轻油门、全油门、制动与手刹作用分开；焦点丢失或暂停释放踏板，防止卡油门。

车身碰撞使用从模型提取的俯视凸轮廓，避免原胶囊边界漏掉车头角部；凸轮廓有意不覆盖后视镜、天线等装饰件。动态路障仍使用简化刚体。程序化车型增加曲面分段；导入车型使用一次受限曲面细分，角点移动不超过 4.5 厘米、三角形数最多增至原来的四倍，并跨材质接缝保持窗框对齐。保留适度 poly 风格。

后视镜改用独立渲染目标与水平翻转合成，避免倒置投影导致的背面剔除问题；校准车身外侧镜位、视场及俯仰。车头摄像机移至挡风玻璃基部，消除导入车型立柱遮挡。

发动机声音随负载与转速平滑变化，燃油与电驱区分音色；碰撞声音随冲击强度变化。删除菜单背景音乐生成器，保留按钮与点火音效。

## 场景与来源

第一关改为北京东四片区：东四北大街、朝阳门北小街、东四十条、朝阳门内大街，以及东四二条至九条。依据北京市公开的《东四三条至八条历史文化街区保护规划（2023—2035）》公示稿图 02 手工提取街巷中心线与连接关系。

来源：https://www.beijing.gov.cn/hudong/gfxwjzj/qjzjxx/202504/P020250417415995633374.pdf

图面以 1800 像素宽渲染，200 米比例尺约 214 像素；游戏采用每米 10 单位。手工提取存在误差，路宽、建筑、路牌和绿化为合理简化，未逐栋或逐条核对现场设施。蓝色 P 停车区是明确标注的虚构训练设施，不代表真实停车场，也不表示现实交通规则或停车许可。

道路不再随机交错。主要道路按方向分隔，胡同不绘制虚假的多车道分隔线；路口截断中心线，配置人行横道、停止线、街名牌及训练限速牌。院落体量和行道树避开道路及路口。修复公共箭头、掉头与让行标记的形状和地面方向。

第二关扩大车库通道和车位；第三关改为有连续通道的斜列停车。第四至第六关保留原训练布局，沿用共用车辆、碰撞和标线渲染修复。

## 验证

- `npm run typecheck`：TypeScript 检查。
- `npm test`：7 车型的圆周闭合、前进/倒车轨迹可逆、内外轮转角、方向盘比例、换挡保护、转速关系；实际 GLB 解码的四轮/前轴绑定；碰撞角部与分离判断；6 关出生点和地图边界。
- `npm run build`：生产构建。现有单包体积较大，Vite 仍提示 chunk size 警告。
- 浏览器实测：北京场景加载、道路及三面镜子显示、加速、运动中倒挡拦截、停车后倒车、制动与驻车。

加速校准数字由同一动力参数的离线模拟给出，不作为实测车辆性能认证。声音为程序合成；浏览器已验证音频图初始化，无专业声学或真实车辆录音对比。
