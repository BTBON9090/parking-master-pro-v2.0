# 第三轮驾驶 / 显示 / 北京场景扩展 · 2026-10-22

本轮保留第二轮已通过的输入焦点隔离、设置真实暂停、60 Hz 固定纵向步进、四轮/前轮转向绑定、凸轮廓碰撞、水平翻转后视镜和按钮/点火音，不恢复菜单背景音乐，未修改任何车型 GLB/程序化模型资产。

## A. 驾驶、仪表与第一人称

### A1 取消蠕行与静止保持

- `utils/longitudinal.ts` 删除怠速蠕行；在挡（R/1–5）且速度 < 0.06、无油门需求时，静止 4 个固定步后进入自动保持，速度钉为 0。手刹松开仍保持；N 挡不保持，坡上仍可溜车。
- 8 秒确定性测试：30/60/120 fps 下速度始终为 0。实机已由 Codex 验证 1 挡与 R 挡松手刹 8 秒静止通过。
- W 轻踩目标 40%，Shift+W 为 100%，松开 Shift 回到 40%；测试读到 `0.40 / 1.00 / 0.40`。
- S 制动仍优先于动力；N 给油不移动；松油滑行 1 秒由 2.00 降到 1.785 速度单位，不会瞬间清零。

### A2 燃油手动训练挡位

- 每车使用游戏训练标定的挡位极速/牵引力曲线（参考公开同级数据，但不是任何车型的实车手动挡认证或实测参数）；3–5 挡加入低转速结合区间（`gearMins`），低挡保留自动离合辅助。
- 4/5 挡静止给油先拖挡，1.25 秒后触发熄火：物理循环派发 `engine-stalled`，App 将点火设为关闭并释放油门，HUD 提示“挂 N/1 挡，按 B 重新点火”。重新点火后如果不能量输出仍会再次拖挡/熄火，不会无声锁死。
- SU7 / YU7 单速电驱不进入多挡/熄火逻辑；HUD 标注单速电驱、无多挡/不熄火。
- HUD 档位教练在有升挡、降挡、高挡低速或熄火风险时显示建议速度带；平时由仪表显示挡位/速度，不长期遮挡。
- 训练提示明确：挡位是游戏燃油训练标定，不是这些车型现实手动挡认证。

### A3 后视镜 DOM 内框实测

- 新增 `utils/mirrorLayout.ts`：UI 用 `ResizeObserver + getBoundingClientRect` 测量三个镜片**内框**（边框内、实际圆角），将 canvas 相对 CSS 像素、DPR、canvas 尺寸发布给 GameCanvas。
- `GameCanvas3D` 的 scissor/viewport、相机 aspect、圆角遮罩全部使用同一内框；仅第一帧使用公式 fallback。窗口 resize、浏览器缩放、滚动通过 `resize`、`visualViewport`、`scroll` 重新测量。
- 镜框圆角/画面比例按内框对齐；Three 的 viewport 用 CSS 像素，像素比由 renderer 自行换算。

### A4 第一人称驾驶员眼位与座舱

- `resolveHoodCameraLocalPose` 改为左舵驾驶员眼位：约 0.16 车宽左偏、0.72 车高、车身中心略后；默认 FOV 66°，方向盘/仪表台/两侧 A 柱自然入镜。
- 新增轻量程序化座舱（`three/driverInterior.ts`）：仪表台、仪表屏、方向盘（半径 1.8 世界单位 = 360 mm 直径）、A 柱。第一人称方向盘随输入联动；A 柱延伸到视口顶部之外，不再出现横穿天空的顶梁或悬空竖条。
- 第一人称隐藏原车外壳 mesh/rig，避免从车内看到白色车壳、窗框等内外穿插；后视镜渲染和左上俯瞰 pass 临时恢复外壳，避免辅助视图只剩黑影。内饰组在后视镜/俯瞰/外部视角隐藏。
- UI 第一人称只保留缩放后的仪表总成（无两个悬浮方向盘），实体方向盘不再与 UI 方向盘重复；挡位教练仅在需要提示时出现。
- 实机截图迭代：`docs/round3-cockpit-failure.png`（巨大方向盘/车壳浮件）→ `docs/round3-cockpit-intermediate.png`（车壳浮件、顶梁）→ `docs/round3-cockpit-intermediate2.png`（外壳浮件消失，但无仪表）。据此最终修正：第一人称恢复缩小的主仪表（无 UI 方向盘），左上俯瞰渲染 pass 临时恢复车身，删除横穿天空的顶梁/侧顶轨/中央镜杆，A 柱加长到视口顶部之外；方向盘半径 1.8 世界单位（360 mm 直径）。最终截图待复验。

### A5 高速转向与可控漂移

- 速度敏感有效锁：25 km/h 以下保留机械满舵，向高速平滑降到约 24%；方向盘输入被同步压回有效锁，前轮/车身/辅助线不再出现满舵大打但车不转的夸张差。
- 高速急转或手刹+转向进入有上限的短时侧滑（最大约 0.22 rad），松手/松刹后衰减恢复；侧滑触发胎痕/打滑声，不改变固定步进。测试覆盖进入、上限、恢复和低速不触发。

## B. 北京场景与交通

### B1 建筑替换与统计

- 原 270 单位密排小院网格 → 粗粒度大建筑：31 个厂房/仓库/停车楼/服务建筑，满足 30–60 个目标。按复验口径，旧密排**建筑为 850 个**；旧场景另有 **853 件总墙件**（墙件/碰撞件，不等于建筑数）；新建筑数较旧建筑数减少约 **96.4%**。
- 建筑按区域 bucket 实例化（body/roof/windows 分组合批），保留视锥裁剪；树/路缘/NPC 也使用实例或共享资源。
- 新增厂区大型建筑、东侧仓库、装卸区、厂区停车坪与训练扩展标识。明确标注为北京风格训练扩展，不宣称实地复刻。
- 建筑与道路 SAT 测试通过；NPC 初始位置不与建筑相交；路边车位不与车行道相交。

### B2 道路、路口、地面细节

- 保留东四主街骨架，新增 2 段可行驶曲线：厂区闭合环线 + 接入训练停车区的 S 弯。曲线有实际路面、自动标线、地图折线；建筑避开曲线，NPC 路线使用同一环线。
- 主街交叉口增加圆角路口补片；主街路缘按分段实例化，路口附近断开。
- S 弯与厂区环线连接口新增三臂 T 形圆角补片（`bj-junction-loop-t`），并把连接口设为两条曲线路的 `markingGaps`：两侧边线、导流虚线、路面导向箭头和道钉在 125 单位半径内全部裁掉，彼此不再贯穿/交叉。真实路口截图见 `docs/round3-junction-review.png`；修复后需最终实机确认。
- 地面换成带颗粒/接缝的低对比 Canvas 纹理；主街新增暗色伸缩缝与两条轮迹标线；车位、路缘、路牌提供尺度参照。
- 默认接触阴影：车辆、建筑、停车车辆使用低成本 radial blob；太阳阴影仍是可选设置，未给所有树开高分辨率阴影。

### B3 路线小地图

- 右上路线地图的玩家标记从地图坐标小箭头改成固定像素高对比“白圈+青色箭头”，按 SVG `xMidYMid meet` 的 letterbox 变换真实定位；使用 ResizeObserver 测量地图可视区，适配窗口缩放/裁剪/楼层 viewBox。
- 1153×702 小窗口布局回归：移除根容器 `min-width:1180px/min-height:700px` 强制尺寸，右后视镜/路线地图/训练提示不再被推到视口外；第一人称仪表改为真正居中并按左右后视镜之间剩余宽度缩放（1153px 时 gap 459.3、仪表 329.2），不覆盖镜面；训练提示在 <1280px 默认折叠为按钮，可手动展开。布局计算提取到 `utils/hudLayout.ts` 并有 1153/1457/1731/2007 断言。
- 标记随 `car-map-position`（约 12.5 Hz）实时更新，尺寸不受地图缩放影响。

### B4 NPC 交通

- 第一关默认 8 辆活跃 NPC，代码上限 `MAX_ACTIVE_TRAFFIC = 8`。路线为厂区环线，沿实际连通车道转弯。
- 近玩家每帧更新；450–900 单位 18 Hz；更远 9 Hz。dt 使用真实经过时间，靠减速/停车而不是瞬移。
- 前车/玩家在 140 单位固定停止窗内则停车等待；不会硬穿停放车辆。被玩家堵住超过 2.2 秒后偶尔鸣笛，冷却 8.5 秒。
- 接触时按从阻挡者指向 NPC 的方向做 ≤2.4 单位的有限分离，速度归零并进入 1.2 秒恢复锁定，然后继续路线；不做远距离弹射。
- 单元测试：路径跟随、玩家阻挡停车、鸣笛冷却、重叠分离；实机手感/鸣笛音量未验证。

### B5 停车设施

- 保留训练停车区，新增厂区 6 个并排车位（2 空）、主街 4 个路边平行车位（2 空），均为可停车目标；其余放置静态已停车辆。
- 车位避开路口、斑马线与主车道；主街车位经 SAT 检查不在车行道内。
- 增加装卸区和厂区停车标牌；未扩散做公交站/大型服务区。
