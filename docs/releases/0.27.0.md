# 老司机是怎样炼成的 · 0.27.0 体验测试版

本次重点改善安卓触控、持续负载、车辆比例和碰撞体验，保留应用标识及 Android 签名，可覆盖安装并保留设置。

- 方向控制改为可调位置、尺寸的四分之一圆弧，高速继续放大刻度；减少触屏拖动造成的重绘，保留各车型方向盘行程。
- 优化方向盘换手与手臂，加入驾驶位前后、高低、视线俯仰设置；这组设置移动眼点，座椅模型本体不移动。
- 修正大巴、重卡轮径和宽高观感，以及挂车、矿卡、中巴和长轴接驳车的轮胎/轮拱间隙；履带演示轮组和履带加入可见转动及悬架表现。
- 雨、雪、雾可单独开关或组合；减弱高速模糊，调整高速护栏、弯道提示及建筑与道路的对齐。
- 驾驶、后视镜、车库预览与后台分别限制渲染频率；复用碰撞查询、路面采样与静态物理结构。桌面回归通过，不代表安卓温升已改善。
- 车库动力试听默认关闭；总静音释放音频资源，暂停/后台挂起音频图。修复静音按钮被镜面挡住，总静音保留独立声源设置。
- 碰撞车损按相对速度计算，移动 NPC 的速度参与质量冲量；被撞停的 NPC 从静止重新起步，侧向滑行同步到物理体。玩家高速事故使用数量受限的碎片效果。

已完成代码完整回归、TypeScript 检查、桌面浏览器检查与安装包构建/资源一致性核验。涉及资产的修改保留 Blender 渲染与游戏内检查记录。

**本次发布未做新的 Android 实机、高速长测或温升验收。** 原应用内浏览器曾出现音频恢复挂起，独立 Chrome 连续恢复检查已通过，Android 前后台恢复仍需验证。L80 A 柱精修、NPC 完整散架尚未完成；逐轮驱动/差速器只在开发环境隔离实验，正式模式仍是原简化动力模型。

Mac / Windows 未签名；iOS 提供工程 ZIP，暂无可安装 IPA。模拟参数为游戏标定，不代表原厂级仿真。
