# 0.27.1 · 天气独立设置与输入恢复

- 白天 / 夜晚可在出发设置和驾驶设置中单独选择并保存，开启天气或重新进图不再随机变成夜晚。
- 雨、雪、雾仍可独立组合。雨雪粒子跟随道路海拔，修复高山路段天气落在脚下；降雪速度按经过时间计算，30–144 Hz 数值轨迹一致。切换雾与时段复用现有雨雪缓冲区。
- 按住油门时重置车辆会清空旧触控记录，旧手指移动不会重新踩油门；切后台释放键盘及触控踏板，返回后重新操作才生效。
- 修复 V 键被雨刮功能拦截：V 挂空挡且不自动拉驻车手刹；K 开关雨刮，考试面板和引导同步更新。自定义按键优先于固定附属快捷键。

验证：数值回归、桌面 Chrome 游戏内天气八种组合、设置保存、双触点重置和后台事件检查；多平台构建及资源一致性另见 docs/round42/VALIDATION.md。

本轮没有修改车辆模型或正式驱动算法，没有 Android 实机测试。按用户要求暂缓温升、A柱遮挡、NPC完整散架、正时 / 正式逐轮驱动问题。雨雪仍是有数量上限的视觉近似，不代表完整气象或隧道遮雨仿真。Mac/Windows安装包仍未签名；iOS提供工程ZIP，不提供IPA。
