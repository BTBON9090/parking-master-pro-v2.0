# 0.28.0 · 保存旅程，连通地图

- 新增本机游戏进度：每5秒、退场及切后台自动保存，驾驶设置可手动保存，主菜单可继续上次驾驶。保留车型、地图、安全位置、奖励、停车完成项和考试成绩。恢复时停稳、N挡驻车；不恢复正在踩住的踏板、碰撞碎片或半途考核动作。主档损坏时尝试备份；地图修订或原位置被占用时回到该地图安全起点。
- 触屏转向以落指处锚定当前方向，后续相对拖动；重新抓握不跳转，刻度继续随车速自适应。
- 首页、选车、选图右上角加入设置。每个新版本首次显示变化说明，可在设置“关于我的介绍”再次查看。手机不再显示遮挡路面的键盘快捷提示。
- Android 支持应用内下载更新、校验并打开系统安装器。校验大小、SHA256、包名、新版本号和应用签名，支持取消、失败重试。系统确认和首次安装权限仍由用户处理；覆盖安装保留本机进度。0.27.1及更早版本需要先从下载页安装本版本，之后才具备应用内安装能力。
- 综合试验场说明上移，隐藏中央后视镜，保留左右镜；按实际位置识别考点，允许非顺序练习，离开区域停止套用旧项目规则。停靠项目仍要求在指定位置停稳。
- 青岚山路面采样剪枝降低CPU工作量，保持渲染三角面接触；护栏检查整段交叉关系并留出路口。修复宽停车坪与窄山路相接时路面支撑高度不一致。
- 云顶路线加入不同半径回头弯与长弧，山顶可发现罗盘彩蛋。整车停入升降台后可往返云顶与山腹，80秒游戏升降动画可跳过；山腹涵洞通向城市。升降机与地下通道是当前框架内的程序化场景。
- 地库南端新增双圈螺旋坡道，B1直达B3，原东侧逐层坡道保留。城东通道分别连接地库B1和高速服务区，驶入后自动切换地图并保存上一张地图的完成项；到达后重新起步。

存档保存在当前设备，不是云同步。卸载或清除应用数据会删除；不同设备不会自动共享。当前开放地图/车辆没有新增付费解锁。

验证与边界见 docs/round43/VALIDATION.md。桌面游戏、数值回归与Android模拟器验证分别记录；不以模拟器结果承诺手机帧率、温度或厂商安装器行为。车辆资产与正式驱动算法本轮未更换；Mac/Windows安装包未签名，iOS仍为工程ZIP，不提供IPA。
