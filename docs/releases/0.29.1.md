# 0.29.1 · 山路渲染与车辆修复

- 青岚山道路、路肩和标线按空间分块，主镜头与后视镜可剔除视野外的路面；保留原有道路三角面和高度。单个本机场景视角下可见道路相关三角面由约91.8万降到9.1万；离线场景构建约4.87秒变为4.94秒。数字是单视角 CPU/几何对照，不是手机帧率或固定性能保证。
- 修复运输起竖车活动网格从枢轴脱离，游戏内可见发射筒起竖和支撑腿展开；增大轮胎并增加两侧储箱。起竖和倒数自动切外部镜头，发射镜头围绕导弹跟随，可拖动视角；加入程序化起竖、发射与爆炸音效及风格化蘑菇云。真人听感和拖动操作仍待进一步验收。
- 隧道出口改接城市北侧道路，清理道路及路缘；山顶最后一段增加缓坡控制点。新出口实车驶入城市通过，山顶全线仍需实测。
- 驾校 S 弯及标牌避让调整；城市两条主街增加小幅起伏。驾校全部路线和项目顺序的全面重排尚未完成。
- 高速大地图扩建、完整山间高速及山谷高架仍在开发，本版本未包含这些新路段。
