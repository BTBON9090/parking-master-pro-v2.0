# 0.30.0 · 驾驶视角与卡车操作

- 驾驶中可调整座椅前后、高低和俯仰，并按车型保存。新增路线车头和车尾视角；点击切换、长按选择，触屏自由视角支持双指缩放。
- 高速新增掉头路段与标记；两款半挂卡车可停车分离车厢，并挂倒挡对准后手动对接。
- 调整后视镜、按钮、提示栏及路线图位置；转向弧增加固定刻度内圈，新增转向灯和雨刮按钮。
- 车底接触地形或路缘时增加碰撞声和轻微损伤；起竖车采用分阶段支撑、起竖、点火、发射和收回，支持自由观察，并配合程序合成音效。
- 类型检查、生产构建、专项测试，以及浏览器座椅持久化、横屏布局、视角菜单和停车分离/对接检查已通过。真实双指、长距离倒车和真人听感尚未实机验收。

覆盖安装前请保留原应用和存档。iPhone / iPad 暂无可直接安装版本；iOS ZIP 是 Xcode 工程源码，需要 Apple 签名和适用的分发渠道。
