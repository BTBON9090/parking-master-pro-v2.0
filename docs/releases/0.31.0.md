# 0.31.0 · 爆点反馈与半挂驾驶

- 爆点增加持续火光、浓烟、扩散冲击波、密集碎片、地面碎石飞溅与短暂的镜头震动；附近玩家车辆及可独立定位的汽车、建筑、桥梁护栏等可被破坏。为控制性能，单次处理最多 24 个场景对象，其中最多 3 辆 NPC 车使用真实模型碎裂；连续桥面、道路和地形暂不拆解，仅显示爆点碎屑。
- 两款半挂车脱挂后按估算的车头质量重新计算加速、悬架与碰撞，对接后恢复整车组合质量。两车均为手动变速箱，一挡约 5 km/h 达到限速，须手动升挡。质量为游戏模拟值。
- 包含上次尚未发布的运输车演出与视角操作：可在发射后返回车身并收回支撑，导弹继续飞行；更新弹体、尾焰、烟雾和警戒音。相关音效采用程序合成。
- 更新半挂车架和分离支撑、驾驶界面、车型雨刮、500 米路线图和可调高速车流难度。
- 建议覆盖安装并保留原应用数据。Mac/Windows 安装包未签名；Android 延用原签名；iPhone/iPad ZIP 是 Xcode 工程，尚非可直接安装的版本。
