# 0.32.0 · 高速车流与驾驶体验

- 高速主线四条车道的无障碍目标速度由左至右为 110、100、90、80 km/h；跟车、弯道、事故等情况会减速。修复护栏导致 NPC 错误停车，并改善变道检查。
- 减少隐藏俯瞰画面的额外渲染；触屏自动画质降低后视镜和阴影的渲染开销。实际帧率随设备和场景变化。
- 左右转向灯增加闪烁同步提示音。发射、飞行和爆炸采用真实录音剪辑：航天飞机发射和受控爆破录音用于游戏效果，并非导弹或核爆实录；素材来源和授权随应用提供。
- 导弹可在全局俯瞰地图缩放、选点并确认后发射；移除行车提示中多余的非铺装传送按钮。
- 建议覆盖安装并保留原应用数据。Mac/Windows 安装包未签名；Android 延用原签名；iPhone/iPad ZIP 是 Xcode 工程，尚非可直接安装的版本。
