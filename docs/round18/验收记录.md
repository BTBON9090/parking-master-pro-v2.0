# 第 18 轮：转弯稳定性、悬架回弹与原地恢复

日期：2026-10-25。Codex 直接实施；未修改 Blender 模型。

## 根因与修改

- 原漂移逻辑在受抓地限制的转弯轨迹上另加横摆和横移，再把额外横摆当作侧向加速度传给悬架。这会凭空扩大载荷转移，误触发翻滚。现在车身侧滑角与轨迹方向分别处理，前后轮合成曲率受抓地限制；悬架使用轨迹产生的实际侧向加速度。
- 原悬架即时套用路面姿态，强制限制车身最大高度，触及限制就清空回弹速度。现在车身俯仰、侧倾、升沉经过质量/弹簧/阻尼响应，保留悬架压缩后的速度，仍限制各轮机械行程并防止轮胎穿地。
- 支撑高度沿行驶路径分段采样（通常不低于 120 Hz，20 cm 空间间隔，单帧最多 24 步），避免低帧率跳过窄凸起。已接触的路肩仍有克服高度所需的能量损失。
- 越过凸起后若四轮已无法触地，保留世界竖直速度进入重力抛物运动。离地期间不让油门/刹车/转向凭空改变水平运动，落地后保留冲击速度交给悬架收敛。
- 重置走独立恢复事件，不再重建关卡。清除损坏、翻滚、漂移和输入，恢复点火，空挡驻车；保留车辆位置、朝向以及自由视角/缩放。解体恢复使用最后车辆位置，而非可能飞出地图的碎片平均位置。设置按钮改名“原地重置车辆”，R 键同样可用。
- 暂停释放按键与拖拽，但保留座舱转头方向，防止通过设置恢复时先被自动归正。

实现参考了 [PhysX 官方车辆文档](https://nvidia-omniverse.github.io/PhysX/physx/5.6.1/docs/Vehicles.html) 对弹簧阻尼、悬架行程及失去轮胎支撑的分离处理。当前仍为轻量自定义车辆模型与 Cannon 刚体翻滚的组合，未宣称接入 PhysX 或达到工程级轮胎仿真。各车悬架参数属于模拟标定。

## 自动检查

- `npm test` 全套通过；新增动态回归和生产山地采样脚本通过。
- `npm run typecheck`、`npm run build` 通过。构建仍有既有的大 JS chunk 提示。
- 五个实际 GLB、72–198 km/h 的受抓地限制转弯、左右换向：无虚假离地/翻滚；最大侧倾约 1.43–3.25°，车底最小间隙约 12.55–16.50 cm。
- 原有组合坡度、横坡、四轮转向/接地、轮眉轴位、快速平滑下坡，以及 60° 陡横坡真正翻滚的回归仍通过。
- 同车同路，仅改变阻尼：26 cm 下坎之后，低阻尼的余振路程约为正常阻尼的 5.5 倍；低速没有被伪造成整车腾空。
- 独立短坡剖面，90 km/h：约 1 s 腾空；15/30/60/120 FPS 的最高高度差小于 1 cm，空中加速度为重力，落地后收敛。
- 真实青岚山高度采样：指定 7.2 km/h 行进保持接地；指定 90 km/h 时在山脊处累计离地 1.23 s。此项是隔离悬架的给定轨迹/速度测试，不代表键盘油门在该坡上能保持恒速。

数值结果：`dynamic-regression.json`、`mountain-contact.json`。原 GLB 接地回归仍写入 `../round16/chassis-regression.json`。

## 游戏内独立验收

使用应用内浏览器的普通界面及键鼠；没有注入游戏状态。

- 钛7，从空地加速到约 108 km/h，再持续左转；约 94–95 km/h 读数为 -0.71 g、侧倾 2.2°，四轮接地且间隙约 0。无损坏提示。截图 `high-speed-turn.png`。
- 实体 26 cm 路肩，助跑约 27 km/h 越过：前轮先落地、后轮压缩约 11.4 cm，车身相对支撑平面下沉约 6.1 cm；随后归稳。`kerb-crossing.png` 是越肩后的侧面截图，动态读数来自同次 UI 抓取。轻油门从静止顶路肩仍会受阻，保留越障阻力。
- 自由环视下普通重置，位置 X799/Y665、视角类型及方向保持；见 `reset-before.png`、`reset-after.png`。
- 正面严重碰撞解体后仍可拖拽环视；点击恢复后仍在 X2450/Y4132，空挡驻车、损坏清除、自由视角保留；见 `wreck-before-reset.png`、`wreck-after-reset.png`。
- 一次早期人工测试因工具调用间隔内继续直行而撞到世界边界，不能计入转弯结果；之后以连续加速/转向操作独立重测，通过上述高速转弯检查。

## 范围

保留真正的重心越界翻滚与障碍碰撞损坏；没有通过关闭损坏或禁止所有翻车来掩盖问题。轮胎柔性、空气动力和复杂悬架连杆仍为简化模型。当前轮胎与模型共用车身姿态和固定轴位。
