# Round 23 — Android 操控与清晰度修复（0.22.1）

## 实现

- 独立 pointerId 管理转向、油门、刹车与临时手刹。所有动作按钮在 pointerdown 响应非主触点；键盘/辅助操作仍可通过 click 激活。取消、失焦、暂停、换车均释放临时输入，保留 P 驻车状态。
- 移除原生转向 range 控件；仪表左侧区域横向拖动负责转向。连续踏板由 12% 起步，上滑 100 CSS px 到 100%，下滑可减小到零。制动优先，松开刹车时仍按住的油门恢复原请求值。
- 修复触屏油门误设 gasPressed=true，导致物理引擎强制使用键盘 W 的轻油门值的问题。键盘 W / Shift+W 原有力度不变。
- 紧凑图标工具栏；启停、灯光、驻车与手刹移到右上，仪表下移。电驱自动挡只显示 R/N/D，燃油皮卡显示手动加减挡。仪表右侧单一力度条：油门红色、刹车绿色。
- 镜面 shader 在合成前丢弃圆角外像素，移除旧版会留下黑色方角的清屏条带，桌面和手机共用。
- 提升车内柔和低频/低阶谐波与路面反馈。胎噪在车内仍有约 10.9–14 dB 的幅度衰减；保留滑行无驱动音的门控。为模拟混音标定，不代表实车声压测量。
- 自动清晰度保留换车前的渲染比例；排除加载、暂停、后台和长间隔，预热后用帧时间中位数评估。持续低帧才降级，稳定 60 Hz 允许恢复，手动画质不自动降低。
- 车损提示改为边缘短状态条，手机单行约 22 CSS px 高；事故后继续模拟，保留重置入口。

## 已验证

- `npm run typecheck`、完整 `npm test` 通过。
- 新增生产控制器回归：先转向再油门/刹车，三个不同触点独立保持；错误触点无法释放或抢占；连续上下滑、松手恢复、取消清理与红绿反馈选择。
- 全部车库动力系统接收实际连续油门；动力随力度增加至轮胎抓地上限；满刹可以停车。燃油皮卡低速大油门受到后轮抓地上限限制，测试允许半踏与满踏都达到该上限。
- 自动分辨率回归：加载停顿不误降，暂停不采样，持续低帧可降，60 Hz 恢复；车型切换保留 DPR。
- 844×390 真实应用浏览器界面：触屏油门 2.2 秒后约 5 km/h，刹车至零；左侧空白区域拖动方向盘至 89°，没有触发相机观察；切换皮卡后出现加减挡。
- 浏览器自动模式换车前、换车后读到的实际画布 DPR 均为 1.00。预览开始时保存的画质为“流畅”0.65，测试先显式切换为自动。
- 手机尺寸和桌面尺寸均目视检查镜面圆角，未见旧版突出的黑色方角。见同目录截图。没有镜面 shader 编译错误；保留已有车模绑定警告。
- Android release 构建成功，持久发布密钥签名通过。ADB 覆盖安装成功，设备包信息为 versionName 0.22.1、versionCode 2201；未清除应用数据。
