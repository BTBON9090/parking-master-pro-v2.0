# 0.22.3 — 碰撞后操控与漂移恢复

## 修复

- 碰撞后的世界速度保留回弹惯性，同时从下一帧叠加驾驶员转向，移除旧实现约 2.5 秒内覆盖正常转向的行为。回正冲量受轮胎抓地力约束，反打方向更快抑制碰撞旋转。
- 降低普通急转的额外后轴抓地力损失；松开手刹后恢复抓地与偏航稳定，保留主动拉手刹甩尾。此为游戏稳定性标定，不是厂商实测 ESC 参数。
- 路线小地图可收成 44px 图标，记住展开状态。
- 镜面角度变化不再反复清空布局测量，拖动按渲染帧合并更新，设置延迟保存，避免回退到错误视口导致闪动。
- HUD 与六款车座舱的方向盘顶部参考点改为低亮度窄条。
- 同一份新绘制图标应用到 Mac、Windows、Android、iOS 工程、网页及下载页。来源见 icon.md。

## 验证

- TypeScript 与完整 npm test 通过。round25 包含六车型、30/60/120 Hz，共 54 条漂移恢复轨迹和 27 条碰撞后控制轨迹，结果见 regression.json。
- 90 km/h 普通转向峰值侧偏约 3.6–4.1°；急转约 9.3–11.8°；主动手刹仍可产生约 37–46° 侧偏。松开输入三秒后侧偏低于 1.5°，随后收敛，没有持续自旋。
- 侧碰后的首个仿真步左右转向立即改变车头角度，保持初始向外回弹；恢复冲量不超过抓地力上限，滑行过程不增加动能。
- 浏览器实测小地图收成单按钮、左右后视镜拖动后边界正常、挂 D 挡按 W 达到 7 km/h、刹停及驻车；控制台无错误。截图 cockpit-map-minimized.png。

## 验证边界

- 镜面拖动通过桌面浏览器复查；目前无线 ADB 未发现手机，本轮尚未在安卓真机完成多指拖镜或驾驶复测。
- 碰撞与漂移的定量结论来自实际运行物理函数的回归轨迹，不将其表述为真机全路段驾驶验证。
- Windows / Mac Intel 无对应实机；Mac / Windows 目前仍未代码签名，iOS 为工程交付而非可安装 IPA。
