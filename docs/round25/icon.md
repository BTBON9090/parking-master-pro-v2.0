# Launcher artwork

Created with the built-in imagegen tool. Opaque master: `build/app-icon-source.png`.
An edit reduced the vehicle to the central launcher safe area before export.
`npm run icons` produces Mac ICNS, Windows PNG input, Android legacy/adaptive,
iOS 1024px, browser favicon and the download-page icon from the same master.

Initial prompt:

Create one polished app launcher icon for a low-poly open-world driving and parking game, used on Mac, Windows, Android and iOS. Square 1024x1024 opaque full-bleed image, no rounded outer corners or transparent margins. A single appealing forest-green SUV seen from an elevated front three-quarter angle, with correctly proportioned body, four round substantial car tyres, subtle rounded edges and deliberately simple sculpted polygon surfaces. Place it inside a clean warm ivory parking-bay corner, with one small curved amber road marking that suggests precise manoeuvring. Deep blue-teal background, warm directional light, readable silhouette and distinct face shading, soft restrained contact shadow. Friendly stylized toy-like game art, not photorealistic, not pixel art, not a generic flat car pictogram. Large car occupies the central 60 percent so it survives circular and squircle launcher masks. Keep all essential car details within the central safe area; background extends to all edges. No text, no letters, no logos, no extra cars, no speed streaks, no busy scenery. Crisp icon readable at 48 pixels.

Final edit: zoom out the composition so the entire vehicle fits within the central 62% of the square; keep the deep blue-teal background full bleed and the parking motif understated.
