# 停车大师 Pro 0.23.0 测试版

- 移动端转向改为位置式滑条；优化低速滑移判定、转向恢复和车灯照射范围。
- 调整渲染清晰度及高速画面的抗锯齿；修正新车模型坐地时的包围盒计算。
- 加入手动挡吉普、中巴、大巴和两辆接驳车，以及泥地、雪地等五张初版挑战地图。

此版本供体验测试：驾校考试场的完整考点、计分和引导尚未完成；五张地图尚需继续丰富。低速闪屏、高速清晰度及操控手感尚未在原安卓手机上复验。新增车型参数为游戏模拟标定。

Android 安装包沿用原签名，可覆盖安装；Mac 和 Windows 安装包尚未签名，系统可能提示未知开发者。iOS 仅提供工程，不是可安装的 IPA。
