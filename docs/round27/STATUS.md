# 本轮工作状态

0.23.0 按用户要求作为测试版分发。下列未完成项目不因打包或自动化通过而视为已完成。

- 触屏转向改为位置对应角度；松手回正。多指输入和滑出边界在单元测试中检查。
- 低速打滑提示改为根据轮胎滑移而非低速几何转向角；车辆横向恢复、高速路肩绊翻为模拟调校，需要实机体验复验。
- 高速后处理增加多重采样，自动清晰度最低值提高；绘制深度改动需要原安卓手机确认是否解决低速闪屏及其性能影响。
- 五辆虚构的低多边形手动挡车辆已接入；尺寸和动力为游戏标定，不是厂商规格。中巴、大巴车内画面、车轮模型与地面接触已在浏览器和回归测试中检查，其余车型与驾驶动态仍需完整实机验收。
- 五张挑战地图为初版，包含雪地和泥地。地面模型与接触高度做了三角面射线对照；场景丰富度、路线难度、完整行驶和性能尚需检查。
- 原综合驾校场尚未重建为带完整考点、评分及下一项引导的考试场；雨刷、灯光、信号、地库等联动考核仍需实现和测试。
- 安卓真机未连接。模拟器或桌面浏览器的结果不能代表原机的闪烁、性能和多点触控表现。

自动检查：`npm test` 完成；`npm run typecheck` 和网页构建通过。上述测试只覆盖已有自动化断言，并不等于全部用户需求已验收。
