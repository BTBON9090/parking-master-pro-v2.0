# 停车大师 Pro 0.23.1 体验测试版

- 加宽客车驾驶舱视野，移除侧窗错误的遮挡面，修正左右外后视镜位置与镜面观察位置。
- 长途大巴使用约 1.0435 米外径的轮胎，视觉模型和动力系统使用同一半径。参考宇通 T12 公开的 295/80 R22.5 规格；游戏车辆本身是虚构车型，不代表该车型的完整参数。
- 移动端仪表盘左侧区域采用手指位置控制转向，顶部刻度显示当前转向；松手回正加快，并保留设置中的关闭选项和速度调节。
- 合并连续路肩的渲染实例，减少场景绘制；刹车痕迹改为连续、较浅的轮胎印。
- 检查各地图停车车辆的初始重叠，并为停车车辆增加质量、受撞位移和阻尼。
- 重新组合金属碰撞音效；严重事故增加烟火与驾驶员逃离的游戏化动画。

仍属于体验测试版：驾校考试的完整考点与计分尚未完成；上版报告的安卓闪屏和高速画面效果需要真机复验。Mac 和 Windows 安装包未签名；iOS 提供工程而非可安装 IPA。

轮胎参考：[宇通 T12 规格表](https://dk.yutong.com/products/T12-param.shtml)。外径根据轮胎规格计算：22.5×25.4 mm + 2×295×0.8 mm。
