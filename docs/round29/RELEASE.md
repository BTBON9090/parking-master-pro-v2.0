# 停车大师 Pro 0.24.0 · 横屏布局与转向修复

- 手机横屏入口、车库、地图选择改为上部大预览 + 底部横向缩略图列表；844×390 下可同时看到约七个选项。训练设置独立滚动，不再被页脚盖住。
- 车库可拖动环视、上下观察及双指/滚轮缩放，最低视角保持在展台上方。设置内座驾、地图、操控布局分成独立分类。
- 新增「设置 → 操控布局 → 编辑屏幕布局」：直接拖拽油门、刹车、仪表盘、挡位、操作栏及三个后视镜，宽高分别调整，保存或恢复默认。左手转向区域默认收窄四分之一；中央后视镜吸顶。
- 修复刹车痕迹的地面高度与坡道贴合；地下车库按当前楼层取样，不再固定在世界高度零点。痕迹连续、较浅且逐渐消退。
- 四款巴士使用 Blender 导出的前置竖向镜壳与镜片；镜面相机直接从模型实测位置安装，避免镜壳遮黑。修改的巴士资产为 6546–7466 三角面。
- 按转弯半径重新校准各车前轮机械限位，去除统一 540° 输入截断，客车可达到完整行程；所有轮胎共用 Ackermann 转向几何。海豹 08 保留公开的 ±7° 后轮限位。理想 i9 根据官方手册采用单向一圈的标准方向盘行程，并加入低速反向、高速同向后轮转向；未公开的数值使用明确标注的模拟标定。
- 驾驶舱音量输出上限提高至之前两倍，录音声源同步放宽混音上限；车外音量仍独立设置。
- 普通火灾逐渐增强、熏黑车体，驾驶员逃离；爆炸立即出现闪光和冲击环后持续燃烧。两种状态都保留变形的主车体，不再触发整车拆散。小零件掉落与碰撞惯性保留。驾驶员爬行/跪姿重新落地。

## 本轮验证

类型检查、生产构建、既有回归测试及新增 Round29 测试通过。新增验证覆盖三层车库/坡道刹车印顶点、布局存储与越界限制、火势增长和车体保留、所有车型的完整输入行程、转弯半径、四款巴士镜面相机无遮挡。

浏览器实际检查了 844×390 横屏的车库/地图/训练选项、驾驶 HUD、拖动布局/宽度调整/保存，以及与游戏共用代码的起火/爆炸验收场景。Blender 已渲染修改资产，游戏中独立检查了长途大巴前置竖镜。

安装后仍需要原安卓手机驾驶验收：低速闪烁、长时间帧率、双指同时驾驶、滑移恢复和声压主观体验。本轮浏览器检查不等同于安卓真机驾驶全部通过。
