# 转向校准来源与边界

10 游戏单位 = 1 米。目标半径统一按**低速外侧前轮轨迹半径**计算，使用轴距、轮距和四轮共用瞬时转向中心求解；实车宣传若未注明半径量法，不能宣称毫米级复刻。前轮表值是等效单轨角，内侧/外侧轮胎实际采用不同 Ackermann 角度。控制器必须允许达到完整机械限位，不再统一裁到 540°。
