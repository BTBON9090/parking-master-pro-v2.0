# 停车大师 Pro 0.25.0 · 驾驶与地图扩展

- 修复碰撞恢复速度覆盖刹车的问题；重刹作用于车辆真实运动速度，保留 ABS 与手刹差异。
- 重调转弯抓地与动力分配，减少持续推头和满舵高速冲出；加快方向盘回正。高重心车辆在激烈转向、支撑载荷丢失时可以侧翻，低重心车辆以滑移为主。
- 触屏方向尺 48 格，每 4 格中刻度、8 格大刻度；随速度均匀放大，边缘可继续拖动平移刻度，油门/刹车上滑行程缩至 44 像素。
- 长途大巴按 12.245 米车长、约 1.044 米轮胎外径重新制作；放宽前轮转角与车灯照明锥。
- 综合驾校加入 18 项连续计分、200 余车位、收费站、涵洞、坡起、曲线/直角弯、灯光雨刮、下沉地库弯道、交通灯、加减速、并线超车和掉头；显示当前与下一考点。
- 新增双向八车道高速、动态 NPC 跟车/变道/鸣笛、服务区、收费站、坡道和互通；城市加入高层组团、住宅、立交连接和路边车位。
- 扩大环城山路至约 23.75 公里路线，最高 1000 米；崎岖地图采用不同路线与非周期地形，加入陡壁、积雪及低附着路面。统一可见路面与物理接触采样，修复地形穿出道路导致的弹跳。
- 新增三轮货车、大小轮拖拉机、18 轮铰接半挂、Cybertruck AWD、Revuelto、Veyron 16.4、尊界 V800、MINI Cooper S Sport，模型均由 Blender 生成且完整车辆低于 8000 三角面。

车型公开尺寸与功率来源见 `vehicle-references.md`。悬架、轮胎力、质心与部分转角是游戏标定，非原厂仿真。普通汽车满舵走圆弧，不承诺零半径原地旋转。考试为游戏化训练判定，不替代正式驾考规则。

提供 Android APK、Mac Apple Silicon / Intel DMG、Windows x64 安装包及 iOS 工程。Mac/Windows 未签名；iOS 工程需要用户的 Apple 开发者签名后才能安装。
