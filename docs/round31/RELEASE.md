# 老司机是怎样炼成的 · 0.26.0

游戏更名，保留 `cn.btbon.parkingmaster` 应用标识、存档键和下载文件命名，旧版可覆盖升级。

- 新增 100 式履带驾驶演示、巨岩 797 矿用自卸车、洲际长头 22 轮超长半挂；车库共 22 种座驾。完整车辆 Blender 资产均不超过 8000 三角面。
- 新增车型的开放轮辐、重车驾驶舱视野、前置竖向后视镜，以及方向盘双手/手臂动画。车库支持默认开启的动力声音试听和品牌标识。
- 初始驻车 P；修复加速时转向输入被刻度缩放吞掉、自由视角拖动反向、重车力度条遮挡；小地图支持缩放，ABS 开关显示状态。
- 半挂牵引车与挂箱分别参与碰撞，修复远离车头的尾部漏检。NPC 按质量响应冲量，减少贴住、抖动和穿透；满足接触及质量条件的重车可压低小车车身并越过。
- 车库车型均可出现在停放车队中；高速服务区增加完整车型展示与多辆半挂。
- 五条挑战路线重新排布；矿场增加不同尺度坑洼；高速加入不规则弯线、隧道、事故路段。改进路口拼接、桥梁/建筑避让及路肩纹理复用。
- 缓存地面采样索引、复用停放车辆几何与材质，修复切换资源时的编译生命周期问题。
- 三版启动图标随版本轮换，本版采用矿卡图标。

安装包：Android、Mac Apple Silicon / Intel、Windows x64；iOS 为工程包。Mac/Windows 未签名，iOS 尚未提供可安装 IPA。

这是风格化驾驶游戏，新增重车的悬架、轮胎力、质心等为游戏标定，公开来源及限制见 `references.md`。不宣称原厂级仿真，也没有更换为其他商业游戏的物理引擎。
