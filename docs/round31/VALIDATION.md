# 0.26.0 验证记录

- `npm run typecheck`、`npm test`、`npm run build:client` 均通过；完整测试输出见 test-results.txt。生产构建保留已有主 JS 包体积提示。
- 22 种车型在 30/60/120 Hz 下验证碰撞残余速度的制动响应、满舵起步；大型矿卡的转向验收依据行驶距离和轴距，避免套用轿车同时间转角。
- 专项验证 SAT 完全包含碰撞、挂箱尾部接触、不同质量冲量/能量、重车碾压支持高度、加速中持续多指转向、全车队停放间距、五条路线的差异化及路口完整接入。
- 新增及重做的车辆已在 Blender 渲染，并在独立游戏构建中检查。资产预算、轮胎数量、驾驶员前方射线及分离车门包围盒见 regression.json。22 轮按几何连通轮胎组件计数，不把合并双胎误当一轮。
- 浏览器实驾：长头重卡默认 P，解除驻车并挂 D 后轻油门起步至 7 km/h，重刹回到 0；ABS 开关状态和小地图缩放可用。检查了重车驾驶舱、竖镜、手臂及车库原生模型。稳定构建检查没有控制台 error。
- 触控布局以浏览器横屏触控模式检查，修复力度条与仪表重叠、小地图与后视镜重叠。最终触控构建中，长头重卡挂 D 并持续按油门可起步至 5 km/h，截图见 ui/us22-touch-final.png。不是安卓真机驾驶与长时间帧率测试。
- Mac arm64、Mac x64、Windows x64、Android 和 iOS 工程各 96 个游戏文件 SHA-256 与 dist 一致，见 desktop-packages.json / mobile-packages.json。
- Android APK 签名验证通过且证书与 0.25.0 一致；版本名 0.26.0 / 版本码 2600，应用标识保持不变。

## 尚未覆盖的范围

- 当前无线 ADB 只检测到模拟器，未连接真机；没有宣称完成新版真机安装或全部道路长时间试驾。
- Windows / Intel Mac 未在对应实体硬件运行，Mac / Windows 未签名；iOS 是工程，尚无 IPA。
- 车门/灯具拆分和车体压低是游戏表现，非结构有限元碰撞模拟；高速 NPC 采用简化跟车、变道和事故避让，并非完整交通仿真。
- 渲染/物理改进保留现有 Three.js 与 Cannon/custom 求解体系。声音和驾驶反馈仍须在实际手机扬声器、不同 GPU 和手型上复验。
