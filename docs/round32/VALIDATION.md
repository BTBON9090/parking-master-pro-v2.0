# Round 32 · 安卓优先优化与验收状态

日期：2026-10-28。目标：优先处理安卓端触控、车辆反馈、高速场景及性能风险；共用源码同步 Web 和移动工程，不代表其他平台真机验收。

## 代码修改

- 触控转向改为左下四分之一圆弧，沿用 HUD 编辑和本地尺寸 / 位置保存；修正双手转向方向，略加强方向盘中心标记。
- 洲际长头 US22 改为现有十挡手动，18 轮 SEMI 原先为手动；修正坦克转向和履带差速符号、中间滚轮绑定与轮缘颜色；材质颜色修改不等于履带轮结构已按真实坦克重制。
- 洲际长头挂车八条被拉伸的轮胎已修正并重建，矿卡前后双胎处已开轮拱；两车型有 Blender 四视角渲染及浏览器游戏内检查，数值和截图见 vehicle-geometry-audit.md。
- 离地驱动轮按前 / 后 / 四驱、油门、挡位做视觉惯性近似。此方案不施加逐轮接触力，不是开放式差速器、单侧打滑或四驱逐轮动力学。
- 去掉高速模糊全屏渲染，保留较小视场变化；静态碰撞网格按旋转长墙的包围盒索引，避免长边界膨胀成巨大正方形索引。
- 高速隧道屋顶不再被误作建筑；护栏加高并按匝道开口，增加急弯黄色指示、远山、城市建筑及第二处隧道；护栏分区实例化以便视锥剔除。远山为远景，不是完整可驾驶山体。
- 超过高闭合速度阈值的严重碰撞使用碎片刚体并继承入射速度，普通强撞不再强制清零。暂时停用碰撞触发火焰（旧火焰会强制车辆停止）；目标 NPC 还没有完整散架。

## 已验证

- 原有完整 npm test 链通过；新增 mobileArc、wheelSpin、collisionGrid、highwaySafety、severeCrashFleet、trailerWheelRoundness 和 miningWheelClearance 均单独通过。最终 typecheck 通过。
- 严重碰撞碎片测试覆盖全部 22 个车库模型的构建、动量、数值与释放；这是 Node 模型测试，不等同手机事故场景。
- 横屏浏览器触控弧形测试：拖动至 +523°，无控制台 error；不是安卓真机触摸结论。
- 安卓真机 USB 识别，旧 0.26.0 可启动；使用原签名安装修订测试包成功，未卸载或清除存档；安卓启动并显示首页，进程近期日志未发现所筛选的致命异常。版本号仍是 0.26.0；此包仅为本地测试，不是已发布版本。
- 用户驾驶首版测试包期间，安卓截图可见左下转向弧及约 153 km/h 速度；后续用户主观反馈和最新版车型验证未收集，不能据此判断流畅或转向正确。
- 温度读数：最初充电中、未作驾驶基线时约 39.2°C，稍后处于菜单约 35.9–36.4°C，用户驾驶期间约 36.0–38.6°C。这些读数条件不一致，不能证明游戏发热得到改善。
- Web/iOS 通用资源经 Capacitor 同步；未完成 iOS、Windows 或 Intel Mac 真机验证。

## 尚未完成 / 待独立复验

- 安卓自动注入触控被设备系统拒绝；按用户要求不调整安全设置。高速、交叉路口、碰撞、切换车型、温升、闪动和帧时间均需用户手动配合或具备许可的设备操作才能验证。
- 除已修正的 US22 椭圆和矿卡轮拱外，其他车型动态轮胎椭圆、后轮穿模、车身过窄及驾驶舱 A 柱仍需逐车型实机复现和双重检查；轻卡、中巴、半挂有较小疑似干涉。
- 逐轮扭矩、独立轮速与地面反作用、开放式差速器及单侧失去抓地时的物理效果仍未实现。
- 所有车型的大规模事故特效、目标 NPC 散架、撞击后的翻滚 / 恢复、手机碎片瞬时性能及火灾替代方案仍需验证或实现。
- 自动优化不等于实际降低发热或保证帧率；需相同环境下固定场景、画质、时长和充电状态的真实对比。
