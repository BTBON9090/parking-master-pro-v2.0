# Round 33 · 安卓触控、碰撞、履带、天气与倒手

日期：2026-10-29。此记录区分真实安卓体验、自动 / 浏览器检查和待实机复验。

## 用户对上一测试包的安卓反馈

- 高速视觉和控制比此前略好；手指触屏加速、刹车与转向时比松手溜车明显卡，擦碰或撞击尤其卡；高速刹车时无法同时有效转向。高速转向在 120 km/h 以上还不够精细。
- 坦克可启动、左右转向方向正确；原有中间四轮及履带运动看不清，缺独立悬架。
- 希望雨、雪、雾独立设置且可组合，避免雨雪强制出现大雾。方向盘超过半圈时手势反向，要求交替倒手。

## 修改与验证

- 触控事件直接同步物理输入，HUD 移动更新限频，按下、抬起、取消保持即时；高车速转向精度提高。浏览器 React 组件使用两根合成指针验证刹车 + 转向及逐指取消，非安卓真实多指验收；键盘 / 触控混用有单元回归。
- ABS 关闭时前轮重刹抱死会显著降低转向能力；保留物理行为，仍需针对安卓实机轻刹、重刹和 ABS 开 / 关分别验证。
- 高速场景静态物理护栏保留每个碰撞盒，按区域合并刚体；损伤网格加保守范围筛选及拓扑缓存。桌面微基准反复碰撞的物理步进中位数 7.914 → 0.203 ms，接触次数前后均 22；不等于安卓 FPS。详见 `../round32/performance/collision-performance.md`。严重散架凸包检测仍有成本。
- TYPE100 12 轮接入独立路面 / 悬架接触，两侧履带增加循环移动齿。浏览器矿场实驾 4–6 km/h，前后截图显示轮毂与履带齿位置变化；`trackedSuspension.test.ts` 覆盖 12 点、单轮凸起与轮滚动。带面仍是程序化视觉表现，不是逐节履带刚体仿真。
- 雨、雪、雾独立开关，可单独或同时启用；只有雾开关控制大雾。浏览器检查仅雨、仅雾、雨雾叠加有区别，雨粒由方点改为细线；雨雪实际抓地、安卓体验仍待验收。
- 驾驶员倒手增加交替松手、移手与再握持；覆盖正反各两圈数值连续性。浏览器大角度目视检查曾出现黑屏截图，未能判定是截图还是游戏画面；倒手和闪动仍需实际复验。

## 无线安装与边界

- Android 无线配对成功，USB 拔掉后可读取设备、覆盖安装和启动；原本 USB 的电脑注入触控权限被拒绝，没有尝试更改手机安全设置。
- 安卓测试包 `release/Parking-Master-Pro-0.26.0-android-round33-test.apk`；SHA-256 `eeacf8f0b55a983873b10b5d02b2d9b022c06aaa177af6f3b4d060b0c18aa61a`；包内 96/96 游戏资源与 dist 相同。版本仍为 0.26.0，是本地测试包，尚未公开发布。
- 本次未充电测试开始前记录约 33.0°C，驾驶过程中读取约 35.1–36.0°C；尚未精确控制测试时长或有受控的旧版 / 新版相同条件对照，不能宣布发热或卡顿解决。
- iOS 工程已同步共享资源；Windows / Mac 使用同一源码但未生成新包或在实体硬件验收。
- 左右驱动轮独立力矩、接地摩擦、开放式差速器和单侧打滑反作用仍未实现，计划见 `../round32/DRIVETRAIN.md`。轻卡、中巴、半挂疑似轻微穿模、部分 A 柱遮挡、碰撞目标车完整散架、火焰表现仍待处理。

## 回归结果

- 本轮 `npm test` 全链退出 0，含新增轮组、天气、组合墙体、多指控制及 22 车型碎片回归；`npm run typecheck` 通过。运行时对 `docs/round31/regression.json` 的测试输出已恢复原文件，保留历史记录。
- 自动检查覆盖算法与既有行为，不等于 Android 真机对碰撞、温升、手势、显示和闪动的最终验收。

## 用户安卓实机反馈（2026-10-29）

- 用户反馈：优化后触屏和碰撞“基本不会卡顿了”。这是单台安卓手机上的主观体验，不代表所有机型和长时性能均已达标。
- 方向盘倒手仍不自然：用户期望手跟随轮圈到顶部并稍过顶部后再松手换握，而不是在底部频繁小幅换手。已继续调整；上一包不能视为该项验收通过。
- 用户随后确认新版可以同时刹车和转向；之前 ABS 可能关闭，但当时状态未记录，不能确定原因。用户反馈速度超过 120 km/h 时刻度不再继续放大，已作为后续修正项。
