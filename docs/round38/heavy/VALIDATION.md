# 重卡轮胎改造（SEMI / US22）

用户要求大巴和重卡车轮直径变为原来的 1.4 倍；本记录只涉及「洲际重卡 · 18 轮半挂」和「洲际长头 · 22 轮超长半挂」。由原半径 0.53 m 调为 0.742 m，直径 1.06 → 1.484 m。该尺寸为用户指定的游戏标定，不是实车厂家参数。矿卡是另一类，本次未调整。

- 牵引车前轮和双胎后轮、挂车的 8 / 12 条轮胎均调整，滚动平面等比放大，保留轮胎原有轴向宽度；相邻轴由原先约 1.3 m 拉开到 1.6 m，避免新轮胎相互穿入。保留 2.55 m 车头标称宽度及 2.50 m 挂车箱体；预览镜头因容纳长挂车会显著拉远，不能据此推断宽度数值错误。
- 因车轮加大，开挖轮拱并清除布尔运算产生的挡轮圆盘、下半圈及 US22 轮内残留。保存了两车各 4 个 Blender 预览及 `.blend`，修改过程可用 `scripts/blender/round38_heavy_wheels.py` 对原版 glb 重放；运行前需提供原版备份，脚本拒绝重复处理。
- 挂车轮悬架目标接触高度与轮速从原本固定 0.53 m，改为各轮自身真实尺寸；独立测试确认两种新轮径以及挂车轮圆度、同侧轮组间距、车身和挂车箱体轮拱的射线采样。牵引车前轮左右最大转向、悬架上下各 0.1 m，轮胎多个轴向切片、每切片 32 个径向方向；该有限采样不能证明全部姿态没有穿模。
- 导出过程中曾遗漏 glTF extras 导致游戏原点和驾驶舱标定丢失，已由独立检查发现并从原文件重新导出，逐项对照确认两车 3 个带 extras 节点的原有字段全部保留，并加入自动断言；本次新加的轮径标记不影响原有字段。
- `tests/heavyWheelSize.test.ts`、`tests/trailerWheelRoundness.test.ts` 通过，`npm run typecheck` 与此前 round30 行为回归通过。游戏内实车画面由独立代理复核，以其最终结果为准；安卓手机仍需真实体验验收。

- 全量车型预算测试提示 US22 布尔修复后超出 8000 三角形；未放宽预算，也未减少轮胎轮廓段数，将挂车轮辐由实心柱改为外侧薄面、隐藏刹车盘减面。最终 SEMI 6634、US22 7930 三角形，`tests/driving.test.ts` 与相关轮胎及运行时测试通过。两车均重新生成 Blender 四视图。
