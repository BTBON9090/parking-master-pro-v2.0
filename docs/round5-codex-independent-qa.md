# 第五轮 Codex 独立验收（2026-10-22）

实施：用户 Chrome 中的 DeepSeek Harness，DeepSeek V4.1 Flash / Max，Car 专项对话「停车游戏帧与转向修复」。Codex 负责方案、源码审查、浏览器实测和复验；没有由 Codex 重写游戏实现。

## 已独立验证

- 最后一次座舱修正完成后，Codex 独立运行 `npm run typecheck`、`npm test`、`npm run build` 均通过。
- 默认轿车实际驾驶：一挡持续重油门稳定在约 38 km/h，二挡约 70 km/h；正常升挡建议分别为 20/38 km/h，与红线分开显示。这是训练齿比，不是车型原厂参数。
- W 轻油门、Shift+W 重油门；挡位无油门不蠕行、降挡保护、高挡起步熄火、EV 单速的自动回归通过。
- 方向盘输入可连续跨过零位。实机发现最初 0.6° 松手吸附范围太小，反馈 DeepSeek 改为 2.2°；随后 SU7 通过句号微调从 -7°、-3° 回到精确 0°，前轮转角为 0°、半径为无穷。Alt+C 手动归中实测有效。
- 默认轿车前方、Alt+J 左看、Alt+L 右看、Alt+K 回正均已截图。抽检 SUV / SU7 发现遮挡，已要求按车型和材质修正，不能沿用此前默认轿车通过结论。
- 音频浏览器状态为 7/7 ACTIVE；静音后为 MUTED，恢复后 ACTIVE；进入非铺装路面切换 gravel。最终浏览器日志保留一条编辑期间 13:56 的历史 HMR reload 失败；最终构建和重新加载成功，没有在最终运行阶段观察到新增错误。
- 非铺装入口按钮可停稳后使用，实际定位到 X1300/Y4490。关闭调参面板后点击，避免面板遮挡。
- 默认轿车驶过地形边缘，四轮接触高度不同、车身约 1–1.6° 侧倾，停稳后不持续振荡。
- SU7 实际驶至 X1431/Y4888，地形高 14.03u（约 1.4m），四轮地面高度 14.43/14.15/13.05/12.91u，四轮行程出现差异；路面层 gravel，车辆可停稳。
- 实测窗口采样 mean 约 16.7–18.1ms，p95 约 21–35ms；不能称全程稳定 60fps。
- 自动回归包含：七车型实际车轮/转向绑定、轮胎比例、15/30/60/120Hz 步进、同坑不同速度/质量的悬架响应、地形网格高度误差、坡道低挡牵引、NPC 跟车与碰撞、道路和建筑布局。

## 本轮实测推动的修正

1. 驾驶室出现车壳封挡、引擎盖下面漏出地面、方向盘出画：多轮截图反馈后修正真实车壳提取和内饰闭合。
2. 中心附近 ±2° 微调难归零：增大松手吸附容差，保留输入中的连续变化。
3. SUV / SU7 驾驶室遮挡：按材质拆分玻璃和车漆，校准各车型眼位与方向盘位置。
4. 非铺装窄路卡被生成 6m 巨墙：反馈改低矮护栏，保留 3m 净通道。

## 边界与未验证项

- 未进行真实罗技硬件输入测试；键盘微调和归中已实测。
- 未主观试听；文件解码、接缝样本、音量状态和触发逻辑验证不等于音质验收。
- 发动机来自同一 Peugeot 107 实录的不同片段；碎石为自行车录音拟音，碰撞为金属拟音。雷达保留电子合成。不是七车型各自实录。
- 内饰为低模适配，车壳、车头、窗框来自本车几何；不宣称原厂内饰一比一还原。
- 悬架为每轮简化弹簧阻尼模型及车身姿态近似，配置按车型区分；不是专业车辆动力学求解器。
- 训练场是北京街巷参考加虚构训练扩展；非铺装地形不是对北京市真实地形的测绘复刻。
- 构建仍有约 1.4MB JS 大块警告；长期低端设备性能未完成专项压测。
