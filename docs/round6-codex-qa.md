# 第六轮：轻踏板、静态车辆、复杂路线与碰撞验收

日期：2026-10-22。Codex 负责方案、复现与独立验收；实现交给 Chrome Car 专项对话中的 DeepSeek-V4.1-Flash / Max。

## 本轮用户要求

- W 很轻油门、Shift+W 轻油门，取消重油门；S 很轻刹车、Shift+S 重刹车、空格手刹。
- 轻加减速时小幅俯仰；强制动姿态更明显，坡度和悬架颠簸独立。
- NPC 全部停进车位或路边。
- 连通的非矩形挑战路线，含环岛、立交及桥下、坡道、S 弯、崎岖路面和停车位。
- 重点修复模型边界与碰撞边界不一致，以及重大体验错误。

## 修改前确认

- 代码中 W=40%、Shift+W=100%；S=100%，松 Shift 不恢复刹车等级。
- 实机海豹 08 一档 W 约 2.2 秒后读数 21 km/h，纵向 0.08 g、俯仰 -1.2°。为单次基线读数，并非峰值测量。
- 主车边界生成按配置长宽裁去顶点；轮胎与镜子排除。NPC 碰撞另用配置矩形，未使用实际模型边界。
- 桥栏通过车头方向跳过碰撞，没有真实的高度分离判定。
- 修改前 npm test 通过；现有尺寸容差不能证明实际碰撞贴合。

## 验收计划

1. W / Shift+W、S / Shift+S、松 Shift、混合踏板、失焦释放及手刹。
2. 同车型同起始速度下轻/重制动距离与动态俯仰；低油门一档起步、N/R/D 与静止保持。
3. NPC 定点长时间观察、重置/切换地图，检查是否停在主车道外。
4. 实际模型共享边界生成的七车型测试；前、后、侧、斜角接触及接触后退出；观察线框和可见外缘。
5. 桥上、桥下高度分离，坡面连续、轮胎接地；S 弯、环岛及复杂路线连接与地图对应。
6. 类型检查、回归测试、生产构建，实际浏览器控制台与帧时间抽样。

## 独立验收结果

### 已通过的独立检查

- 第一候选的 `npm run typecheck`、`npm test`、`npm run build` 均独立运行通过。构建有既有的大 chunk 提示。
- `npx tsx docs/round6-codex-measurements.ts`：海豹 08 在 30/60/120 FPS 下，5 秒 W 均为 16.83 km/h，Shift+W 均为 37.07 km/h；动态俯仰峰值分别约 0.300°、0.634°。
- 同一脚本从 30 km/h 制动：S 21.16 m / 4.88 s / 俯仰峰值 0.442°；Shift+S 3.98 m / 0.88 s / 2.288°。这是游戏动力模型测量，不是真车性能认证。
- 模型模拟中，30% 油门沿实际高架坡度从入口驶上 65u 桥面成功；起步速度 0 和 20 km/h 均可。
- 实机海豹 08：W 约 4 秒读数约 13 km/h，轻微车身姿态；桥面向东行驶、重刹停车，四轮高度保持 65u；继续沿坡下降到 17.7u，再到地面 0u，四轮均显示接地。
- 实机桥下转弯行驶，保持地面高度 0u，未被吸到桥面。
- 实机环岛正面碰撞：车头停在可见岛边，碰撞扣分；R+W 倒车脱离成功，无卡死。线框修复后再次撞击验证，青色车体轮廓与车模、红色岛轮廓与可见岛边一致。截图 `round6-collision-overlay.png`。
- 小窗口 640×630 的 T 面板已改为整体内容滚动，测试点能够通过控件自动滚动后点击。
- 当前浏览器捕获错误日志为空（非对整个运行期间无任何故障的保证）。

### 复验发现并返工的问题

1. 碰撞线框加在异步加载前的占位 scene，导致开关 ON 但不可见。返工后在全新加载场景中验证显示正常。
2. 之前环岛碰撞是小方框、护栏只有可见立柱而连续碰撞、桥墩尺寸不一致、桥高单位混淆。已在实现阶段通过源代码审查要求统一，并实机确认环岛接触及高架通行。
3. 崎岖路地形高约 17.2u，路卡显示被 Cannon 拉到地下且碰撞高度仍为 0。证据 `round6-terrain-collision-failure.png`。已返工统一障碍物高度、静态/动态物体处理及主车 Cannon 高度。
4. 路卡露出地面后仍可穿越：真实碰撞空间索引仅接收 wall/car，漏掉静态 box。第二次失败截图为 `round6-terrain-contact-fixed.png`（文件名保留，实际为索引漏接的失败证据）。再次返工后把共享索引候选路径纳入回归测试。

### 最终候选实机结果

- 从全新页面加载最终版本后，重复崎岖路同一动作：D → 逗号约 2.6 秒预打方向 → W+逗号 3.2 秒。车辆被路卡边缘挡住；再持续 W+逗号 2 秒仍未穿越。R+W+逗号可以倒车退出接触。路卡、车体和线框贴合，截图 `round6-terrain-contact-passed.png`。
- 静态 NPC 实机：碰撞点正对工厂车位 (2040,4195)，本车低速前进接触 NPC 尾部后被挡住，资金 100→90；NPC 保持在车位，红色轮廓贴合可见车体。R+W 倒车脱离成功。截图 `round6-parked-car-contact.png`。
- 最终高度链回归：从桥下入口 (6500,4250) 向南行驶约 8 秒穿越桥下，路面/四轮高度均保持 0；从桥坡入口 (5300,4500) 用 Shift+W 约 10 秒驶上桥面，路面和四轮均为 65u。
- 实机一档同时按 Shift+W+Space 2.5 秒，速度保持 0，手刹优先。
- 最终实机帧时间抽样 mean 16.7–17.0 ms、p95 19.3–25.7 ms；不是全机型恒定 60 FPS 的保证。
- 最终候选独立运行 `npm run typecheck && npm test && npm run build`，退出码 0。新增共享碰撞索引和地形高度回归通过。浏览器最终错误日志为空。
- localhost:3000 单个 Node 监听进程；游戏标签已标记为交付保留。车辆在新桥面以 N 挡驻车，诊断线框和面板已关闭，保留远跟后方视角。截图 `round6-running-game.png`。

## 范围与限制

- 七车型实际模型边界和接触由自动检查覆盖；本轮实机重点使用海豹 08，未逐车逐段路网穷举。
- 碰撞采用实际模型外轮廓凸包及垂直区间，未实现车身凹陷变形或逐三角形碰撞。
- 新路网为虚构训练扩展，保留北京风格旧街区；本轮未新增大型山体或隧道。
- 新停车 pad 可从开放地面驶入，支路铺装、完整交通规则和全部视觉细节仍可后续完善，不作为本轮基本可玩的阻断项。
- 测试输出里旧交通算法单元测试仍会出现跟驰/鸣笛的文字；它只测试保留的纯函数，运行时所有场景已停用 AI 交通。
