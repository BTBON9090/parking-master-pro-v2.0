用户要求保持 Codex 规划/独立测试，DeepSeek Flash Max 实施。只在当前 Car 工作区修改，不干扰别的任务，不提交/推送。最终保留单实例 127.0.0.1:3000。

## 已确认与待复验

- 源码确认 longitudinal.ts 的 stationary autoHold 在带挡静止后锁住坡道车；用户这轮明确要求松脚刹后自然溜坡，覆盖旧规则。平地没有油门不蠕行仍保留。
- keyboardPedals.ts 的 handbrake 会被 gasPressed 清除；改 Space 每次非 repeat keydown 切换锁存，松开 Space 不改变，油门/Shift 不自动解锁，按钮与键盘一致，失焦清踏板但不清已拉起手刹。
- 当前“海豹08”车库显示 FWD/125kW/205Nm/1400kg，实为通用燃油训练占位参数。不得把占位数据冒充真实车型参数。需查官方公开资料，标明版本、来源与估计项；不存在确证的参数明确标训练近似。
- 用户实测待 Codex 复验：转向+油门突然加快；一挡爬坡失败；坡面台阶/共面闪烁/过地形跳跃；离坡坠落俯仰反向；脚刹不能可靠制止溜车；支路被路牙封住；没有停车成功提示；座舱仪表太小/方向盘无辐条/顶部镜过大/重复转向指示器。

## 实施任务及验收标准

1. 动力与制动：保留 W15%、ShiftW30%、S12%、ShiftS100%。力必须沿速度方向正确作用，坡道制动能停车（轻刹制动力足够的坡度可停，陡坡需重刹，有明确反馈）；停止后不能凭 autoHold 粘住。重刹松开且手刹松开应重新溜车。发动机低挡更强制动，N无发动机制动，不能凭降挡瞬间截断车速。允许高速降挡并提示过转/失稳/损伤风险，离合渐进耦合避免瞬移。向后溜车可在合理倒行速度挂R，反方向强行切换仍按速度保护；区分 signed speed。真实EV单速不要套5挡燃油模型，可独立明确提供燃油训练模式。查清一挡爬坡是手刹、扭矩、坡度还是单位问题；30%油门应能在正常训练坡低挡起步/爬坡，不偷加满油。转向不应增加纵向动力，验证直线/定转角同油门的速度与轨迹平滑，检查FPS/重复输入/镜头跟随而非仅改主观倍率。
2. 车型转向：按可验证轴距、轮距、最小转弯半径（注明外轮/车身/中心轨迹定义）反算前轮锁角，低速真实可掉头，高速连续减敏。海豹08按证据加入低速反相后轮转向，速度过渡连续；四轮视觉/轨迹/倒车辅助线/碰撞必须一致，后轮转向不能只做动画。查不到确值用明确训练近似，不能编参数。
3. 地形：全部旧坡道、新桥、窄桥、砂石路排查。mesh与轮胎接触采样共用连续曲面；消除重复面/z-fighting，坡脚/坡顶连续坡度，禁止可见阶梯或跨层吸附。轮胎随接触点、悬架有行程/阻尼，车身跟随不能凭位置硬跳；离地时保持惯性、重力落地，修复前后俯仰符号，平缓慢行不弹跳。路口/支路入口切开不合理连续路缘；可碾压矮路缘进入轮胎高度采样表现前后轮依次颠簸，不能成为隐形墙或如履平地。
4. 停车成功：所有可停车空位（不仅红色任务格）车身完整入框、速度低于0.5km/h并稳定1秒显示显著“停车成功”，停车位高亮、温和提示音（遵从静音）。擦线/经过/车头入框/有NPC占位不成功；同格不重复刷分，驶出后可重新获得反馈。原任务完成流程保留。添加可复现停车验收点，入口姿态方便开进去，不能直接伪造成功。
5. 座舱：放大实际可读仪表约25–35%并检查小窗口不挡路；方向盘补真实中心轮毂和四根辐条（并非所有真实车都有四辐，但按用户偏好实现），连续旋转；中央后视镜缩小约15–20%且镜框图像继续对齐；移除屏幕顶部重复转向指示器，只保留仪表顶部指示器。驾驶室/第三人称同一车辆几何，驾驶室不露胎不穿模。
6. 免费模型：搜索 GitHub 的可用汽车 glTF/GLB，查原作者资产许可证而不是仅看代码MIT。优先曲面自然、轮胎/车轮可分离、可放同一内外模型、适中面数/LOD，必须有至少一个明显改善的实际可选模型接入并离线本地缓存、出处/作者/许可证文件。可用候选为 three.js 官方 examples/webgl_materials_car.html 引用的 Ferrari458（作者vicent091036，原作 https://sketchfab.com/models/57bf6cc56931426e87494f554df1dab6 ）；这是候选不是已确认授权，核实后使用。不能把Ferrari改名冒充海豹，保留车型/训练物理说明；现有国产占位模型适度平滑细化，禁止像素或方盒车。模型接入同步轮距/轴距/车轮旋转/悬架/可见外轮廓碰撞/预览/后视镜，不能只换展示页。
