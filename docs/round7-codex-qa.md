# 第七轮 Codex 独立验收

日期：2026-10-23。实施：用户 Chrome 中 Car 工作区「停车游戏帧与转向修复」，DeepSeek-V4.1-Flash / Max。Codex 负责源码复核、实机复现、派工与验收，没有代替 DeepSeek 承担实现。游戏：<http://127.0.0.1:3000/>。

## 已复现并返修的问题

- 首版用速度/踏板硬阈值叠加起步倍率，改为连续曲线。
- 首版后轮一有转向输入就跳满 ±7°，现按输入比例连续变化。
- 后轮转向节点与轮胎滚动节点混用；中心/后轴路程混用使转弯增加位移，要求统一中心积分。
- 轮距误把半轮距当完整轮距，转向半径公式/测量口径不一致，要求用实际轮中心和共同瞬时转向中心校准。
- 坡下衬由水平盒组成，穿出坡面造成台阶；坡面采样按车头角度过滤，横向转弯会失去支撑；路缘没有轮胎接触高度。
- 普通车位反向停好反而扣 20 分；改为普通车位两个朝向均成功，同格不重复加分。
- 方向盘虽有辐条但被仪表台遮挡；新模型座舱车壳碎面穿透；以实际截图返修，而非接受投影测试。
- 镜子直接在主画布绘制时降低刷新率，跳过帧露出主相机画面；恢复逐帧合成后未再复现该闪烁。
- 真实 GLB 座舱节点被合并优化丢失，随后父节点删除又连带移除保留子树；已用实际 GLB 构建路径复核节点保留。
- 仅保留节点还不足以通过视觉验收：完整重载后仍发现红色薄片、黑色三角和车头/仪表台透视裂缝，已再次返修。

## 浏览器实机

原生窗口 1095×1134，使用正常键盘、相机菜单、T 面板可见测试点，没有隐藏浏览器状态注入。

- 停车：从 (4200,5350) 实际驶入至约 (4298,5350)，完整入框停稳后资金 100→200；驶出再进入约 (4300,5350)，看到绿色「停车成功」和蓝色车位，资金仍 200。截图 `round7-parking-passed.png`。
- 坡起：从桥坡中段 (5650,4500) 一挡 Shift+W 3 秒并重刹后到约 (5681,4500)，正常向上行驶。
- 溜坡与 R：松刹后从 (5650,4500) 向后滑到约 (5632,4500)，约 9 km/h 时成功挂 R；重刹可停，Space 可锁住。
- 手刹：桥坡约 (5770,4500) 拉起手刹，W 1.2 秒不移动；松开手刹/脚刹后会自行滑回坡脚。
- 转向：180ms 左转输入约方向盘 -20°、前轮 -1.5°、后轮 +0.29°，不再跳到满后轮角；Alt+C 回到 0。
- 碰撞：从 (2040,4100) 直行撞静止 NPC，到约 (2040,4144) 停下，资金 200→190；俯视青/红轮廓接近模型外边，未穿过 NPC；可倒车退到约 Y4135。截图 `round7-collision-passed.png`。
- Concept GT 碰撞：同一 NPC 点实驶至约 Y4147，资金100→90，鼻端与 NPC 模型边界接近、无穿车；倒车至约Y4135可退出。截图 `round7-concept-collision-passed.png`。
- Concept GT 砂石：实驶至约(1500,4798)，车体高8.34，四轮接触高度约9.11/9.14/7.36/7.36，均保持地面接触。此项只覆盖该段，未覆盖所有坑洼与悬空坠落。
- 桥坡侧视：车辆前后轮随连续坡面贴地，车头抬起方向正确；并未逐个实驶全部地图坡道。

## 来源及解释

- [比亚迪海豹08官方参数页](https://www.byd.com/cn/parameter-comparison?goodsId=10055)：独立通过 Chrome 查到 5150×1999×1505mm、轴距3030mm、前/后轮距1715/1730mm、最小转弯半径4.95m。页面没有明确半径测量定义，游戏采用外前轮轨迹作为校准口径；±7°后轮上限为训练采用值，不能称已从该官方表核实。5挡手动为游戏训练设定，不是实车 EHS 变速系统。
- [小米SU7官方参数页](https://www.xiaomiev.com/car-config)：独立查到轴距3000mm、最小转弯半径5.7m。YU7的5.9m仍需标训练估计。
- [Khronos CarConcept](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CarConcept)：独立读取原仓库README；Unity Fan原始CC0作品，Darmstadt Graphics Group / Eric Chadwick清理打包版本为CC BY 4.0。本地模型与署名文件已存在。Concept GT是该概念车型加训练参数，不冒充量产车型。

## 最终视觉复验与性能

- 完整重载后，Sedan 前视白色车头与仪表台间的路面裂缝消失，四辐方向盘可见。截图 `round7-sedan-cockpit-passed.png` 只代表前视基本遮挡关系通过。
- Concept GT 前视红色内壳碎面被完整前围遮住，轮毂及四辐可见；截图 `round7-concept-cockpit-basic-passed.png`。现采用同车机盖几何、车窗边界匹配的轻量座舱，并非完整精修原厂内饰。
- 左右转头可用。Sedan 侧看时顶缘仍有粗糙/碎面感，列为已知限制：`round7-sedan-side-view-limit.png`；不将此项写为完全通过。
- 新版 Concept 驾驶视角 W 实驶 3 秒约20km/h，重刹1.2秒至0，Space保持；实时帧间隔均值17.8ms、p95约29.5ms，速度跃变约0.005u。
- Concept 外观同路段实驶原均值33.8ms、p95约92.2ms；移除昂贵玻璃透射后，在明确确认左斜侧前方相机及BODY焦点的条件下，复测W3秒约20km/h，均值17.6ms、p95约33.0ms。为这台机器、此场景的观察值，不代表所有地图/设备。
- 按钮焦点下Space误激活相机按钮已修复：完整重载后，DOM明确确认焦点为相机BUTTON；Space释放手刹（遥测刹车0%）且相机/菜单不变，再长按1秒只拉起一次（100%），按钮未被激活。
- 当前新页面浏览器错误日志为空。外观截图 `round7-game-running.png`。
